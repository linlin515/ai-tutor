## 1. 产品概述

### 1.1 产品定位

AI 学习助手 Android 应用，面向 K12 及大学生群体，提供：
- 智能问答与学科辅导
- 语音交互式学习
- 拍照解题（OCR + AI 分析）
- 多会话管理
- 个性化设置

### 1.2 核心目标

| 指标 | 目标值 |
|------|--------|
| 冷启动时间 | < 2s |
| 消息流式输出 | 不卡顿，首字延迟 < 500ms |
| SSE 连接成功率 | > 99% |
| ASR 识别准确率 | 离线 > 85%，云端 > 95% |
| 数据库 CRUD 响应 | < 50ms |
| 包体积增长 | 不超过 15MB (相比当前基线) |

### 1.3 约束条件

- **架构**：MVVM + Clean Architecture（三层架构），参考 `ARCH.md`
- **语言**：Kotlin
- **UI 框架**：Jetpack Compose (Material3)
- **DI**：Hilt
- **数据库**：Room (本地持久化)
- **网络**：Retrofit + OkHttp + SSE (ChatStreamApi)
- **导航**：Jetpack Navigation Compose
- **认证**：Bearer Token（自动刷新）

## 4. 页面原型描述

### 4.1 启动页 (SplashScreen)

- **URL 路由**：`splash`
- **布局**：居中显示 App Logo + 名称 "AI 学习助手"
- **逻辑**：
  - 检查本地 Token 是否存在且有效
  - Token 有效 → 自动跳转 `main`（首页聊天）
  - Token 无效 / 不存在 → 跳转 `login`
- **加载动画**：淡入淡出，2s 内完成

### 4.2 登录/注册页 (LoginScreen)

- **URL 路由**：`login`
- **布局**：顶部 Logo + 标语 → 手机号输入框 → 密码输入框 → 登录按钮 → 注册切换
- **用户操作**：
  - 输入手机号（11 位，自动格式化）
  - 输入密码（6-20 位，可见/隐藏切换）
  - 点击"登录" → POST `api/v1/auth/login` → 保存 Token → 跳转 `main`
  - 点击"注册" → 切换注册表单 → POST `api/v1/auth/register`
- **异常处理**：
  - 手机号格式校验：11 位数字
  - 密码长度校验：6-20 位
  - 网络错误：Toast 提示
  - 登录失败：显示后端返回错误信息

### 4.3 主页面 (MainScreen)

- **URL 路由**：`main`
- **布局**：底部导航栏 (BottomNavigation)，含 3 个 Tab
  | Tab | 图标 | 页面 |
  |-----|------|------|
  | 聊天 | 💬 (对话气泡) | ChatScreen |
  | 解题 | 📷 (相机) | CameraScreen |
  | 设置 | ⚙️ (齿轮) | SettingsScreen |
- **首次进入**：默认显示聊天 Tab
- **导航守卫**：未登录不可进入（重定向到 login）

### 4.4 聊天页面 (ChatScreen)

- **URL 路由**：`chat` / `chat/{conversationId}`
- **顶部栏 (TopAppBar)**：
  - 左侧：菜单按钮（≡），点击展开会话列表 BottomSheet
  - 中间：当前会话标题（自动命名 / 可自定义）
  - 右侧：新建对话按钮（+）
- **消息列表 (LazyColumn)**：
  - 气泡式布局：
    - 用户消息：右对齐，蓝色/主题色背景
    - AI 消息：左对齐，灰色/表面色背景
  - 消息类型：
    - 文本：支持 Markdown 渲染
    - 代码：代码块样式，有复制按钮
    - 图片：缩略图，点击全屏预览
    - 语音：音频波形图标，点击播放 TTS
  - 流式输出：打字机动画逐块渲染，光标闪烁指示
  - 滚动行为：新消息自动滚到底部，滑动查看历史时暂停自动滚动
- **底部输入栏 (ChatInputBar)**：
  - 左侧：语音按钮（🎤）- 长按进入语音模式
  - 中间：文本输入框（多行，最大 2000 字）
  - 右侧：发送按钮（→ | 上箭头图标），无文本时禁用
  - 附加功能按钮：图片（📷），点击弹出选择：拍照 / 相册
- **状态指示**：
  - 消息发送中：气泡右侧显示旋转加载
  - 消息发送失败：气泡显示红色"!"，点击可重发
  - AI 思考中：显示 "AI 正在输入..." 动画
- **空状态**：无消息时显示欢迎语 + 示例问题卡片

### 4.5 会话列表侧边栏 (ConversationListSheet)

- **触发方式**：点击聊天页面左上角菜单按钮
- **布局**：BottomSheet 从底部弹出，占据 70% 高度
- **内容**：
  - 搜索框：按标题/消息内容搜索历史会话
  - 会话列表：标题 + 最后消息时间 + 消息数
  - 当前会话：高亮 + 指示器
  - 长按选项：重命名 / 删除
  - 滑动操作：左滑删除（带确认）
- **底部**：「新建对话」按钮
- **行为**：
  - 选择会话 → 关闭 Sheet → 加载该会话消息
  - 删除会话 → 级联删除所有消息（本地 Room）
  - 关闭 Sheet → 点击遮罩层或下滑

### 4.6 语音输入面板 (VoiceInputBar)

- **触发方式**：长按输入栏的语音按钮
- **布局**：底部浮现圆形录音面板
  - 中心：麦克风图标，随音量大小动画
  - 提示文字：「上滑取消」、「正在听...」、「识别中...」
  - 状态机：
    | 状态 | 显示 | 交互 |
    |------|------|------|
    | IDLE | 默认语音按钮 | 长按触发 |
    | LISTENING | 麦克风动画 + "正在听..." | 松开 → 提交 ASR |
    | PROCESSING | 加载动画 + "识别中..." | 等待 ASR 返回 |
    | SPEAKING | 扬声器动画 + "播放中..." | 点击打断 |
  - 取消手势：上滑到取消区域松开 → 放弃录音
  - 触发发送：松开按钮 → ASR 识别 → 文本填入输入框（或自动发送）
- **TTS 朗读**：点击消息气泡的扬声器图标 → 文字转语音播放

### 4.7 拍照解题页面 (CameraScreen)

- **URL 路由**：`solve`
- **布局**：
  - 全屏相机预览（CameraX）
  - 底部控制区：
    - 拍照按钮（圆形）
    - 相册选择按钮（最近一张图片缩略图）
    - 切换摄像头（前置/后置）
  - 顶部：返回按钮 + OCR 状态
  - OCR 覆盖层：ML Kit 实时显示取景框中检测到的文字区域（半透明边框）
- **拍照后流程**：
  1. 拍照 → 显示预览确认
  2. 确认 → Multipart 上传 → `POST /api/v1/solve/photo`
  3. 等待 AI 分析 → 显示 Loading
  4. 返回结果 → 自动跳转到聊天页面，AI 解答作为新消息追加
- **相册选择**：通过 ActivityResultContracts.PickVisualMedia 选择图片
- **异常场景**：相机权限拒绝 → 提示引导开启；无相册权限 → 提示

### 4.8 设置页面 (SettingsScreen)

- **URL 路由**：`settings`
- **布局**：分组列表，Material3 Card 样式

**模型与参数 (P1)**
| 设置项 | 控件 | 说明 |
|--------|------|------|
| 模型选择 | 下拉选择器 | 列表来自 `GET /api/v1/models` |
| Temperature | 滑块 (0.0–2.0, 步进 0.1) | 默认 0.7 |
| Top-P | 滑块 (0.0–1.0, 步进 0.05) | 默认 1.0 |
| Max Tokens | 滑块 (256–4096, 步进 256) | 默认 2048 |

**主题与显示 (P1)**
| 设置项 | 控件 | 说明 |
|--------|------|------|
| 主题模式 | 单选 (浅色/深色/跟随系统) | 默认跟随系统 |

**语音 (P1)**
| 设置项 | 控件 | 说明 |
|--------|------|------|
| TTS 语速 | 滑块 (0.5–2.0) | 默认 1.0 |
| TTS 音色 | 下拉选择器 | 本地引擎可选 |

**通用 (P2)**
| 设置项 | 操作 | 说明 |
|--------|------|------|
| 清空对话 | 按钮 + 确认弹窗 | 删除所有本地会话和消息 |
| 清除缓存 | 按钮 + 确认弹窗 | 清理图片缓存等 |
| 版本号 | 只读显示 | `v1.0.0 (build 1)` |
| 关于 | 跳转 | 显示应用信息 |

### 4.9 个人中心页面 (ProfileScreen)

- **URL 路由**：`profile`（从设置进入）
- **布局**：
  - 顶部：头像（圆形，可点击更换）+ 昵称 + 年级
  - 信息卡片：手机号（只读）
  - 编辑按钮：可编辑昵称、年级
  - 退出登录：底部红色按钮 + 确认弹窗 → 清除 Token → 跳转 login

### 4.10 订阅页面 (SubscriptionScreen)

- **URL 路由**：`subscription`
- **布局**：
  - 当前计划卡片：免费版 / 订阅版
  - 配额进度：每日用量 N/5（免费版）
  - 功能对比表：免费 vs 订阅功能差异
  - 订阅按钮（跳转外部支付链接）

## 5. 用户交互流程

### 5.1 核心对话流程

```
用户打开 App
    │
    ├─ Token 有效? ─── 是 ──→ MainScreen (聊天 Tab)
    │                            │
    └─ 否 ──→ LoginScreen        │
                │               ├─ 已有会话? ── 是 ──→ 加载最新会话消息列表
                │               │                      │
                │               │                      ├─ 输入消息 → 发送
                │               │                      │   ├─ 消息写入 Room (状态: 发送中)
                │               │                      │   ├─ POST /v1/chat/completions (SSE)
                │               │                      │   ├─ 逐块接收流式响应
                │               │                      │   ├─ 逐块追加 UI + 写入 Room
                │               │                      │   └─ 流结束 → 消息状态: 完成
                │               │                      │
                │               │                      └─ 语音输入 → ASR → 文字 → 发送
                │               │
                │               └─ 无会话 ──→ 空状态引导 → 新建会话 → 输入消息
                │
                └─ 登录成功 → 保存 Token → MainScreen
```

### 5.2 语音交互流程

```
聊天页面输入栏
    │
    ├─ 点击语音按钮 → 长按触发
    │   ├─ IDLE → 显示 VoiceInputBar
    │   ├─ LISTENING → 用户说话 → SpeechRecognizer
    │   │   ├─ 上滑取消 → 放弃录音 → IDLE
    │   │   ├─ 松开 → 提交 ASR 文字到输入框
    │   │   └─ 识别失败 → 提示"请重试" → IDLE
    │   ├─ PROCESSING → 云端 ASR 备选（长音频）
    │   └─ 识别完成 → 填充输入框并自动发送
    │
    └─ 点击消息 TTS 按钮
        ├─ 短消息 → 本地 TTS 引擎播放
        ├─ 长消息 → 云端 TTS 流式播放
        └─ 可点击其他消息打断当前播放
```

### 5.3 拍照解题流程

```
底部 Tab → 解题 (CameraScreen)
    │
    ├─ 拍照 → CameraX 拍照预览
    │   ├─ 确认 → Multipart 上传 → POST /api/v1/solve/photo
    │   ├─ 重拍 → 返回相机预览
    │   └─ 取消 → 返回
    │
    ├─ 相册选择 → 系统相册 → 选择图片 → 上传
    │
    └─ ML Kit OCR → 实时检测取景框文字（仅提示，不阻断拍照）

上传完成后：
    ├─ Loading 等待 AI 分析
    ├─ 成功 → 自动跳转聊天页面 → AI 解答显示为新消息
    └─ 失败 → 显示错误提示 → 可重试
```

### 5.4 会话管理流程

```
聊天页面
    │
    ├─ 新建会话 → 点击 "+" 按钮
    │   ├─ ConversationDao.insert() → 新会话
    │   ├─ 清空消息列表 → 输入框聚焦
    │   └─ 用户发出首条消息后自动生成标题
    │
    ├─ 切换会话 → 点击菜单 → 会话列表 BottomSheet
    │   ├─ 选择目标会话 → 加载该会话消息
    │   └─ 自动滚动到最新消息
    │
    └─ 删除会话 → 左滑 / 长按 → 确认弹窗
        ├─ ConversationDao.delete(id)
        ├─ 级联删除 Message
        └─ 如果删除当前会话 → 切换到最近会话 / 空状态
```

### 5.5 Token 续期流程

```
发起 API 请求
    │
    ├─ 响应 200 → 正常处理
    │
    └─ 响应 401 → TokenManager 检测
        ├─ 尝试刷新 Token: POST /api/v1/auth/refresh
        │   ├─ 刷新成功 → 更新本地 Token → 重试原请求
        │   └─ 刷新失败 → 清除 Token → 跳转 LoginScreen
        └─ 刷新请求本身 401 → 不重试 → 直接跳转登录
```

## 7. 异常场景处理

### 7.1 网络异常

| 场景 | 表现 | 处理方式 |
|------|------|---------|
| 发送消息时无网络 | 消息发送失败 | 气泡显示红色"!"失败状态，点击可重试 |
| SSE 连接中断 | 流式输出停止 | 自动重连（指数退避 1s/2s/4s，最多 3 次） |
| SSE 重连失败 | 流式输出中断 | 显示"连接中断，请重试"提示 |
| 登录时网络超时 | 登录按钮保持加载态 | 15s 超时 → 显示"网络超时，请检查网络" |
| 图片上传中断 | 上传进度停止 | 显示断点重试按钮，支持重新上传 |
| 网络恢复 | - | NetworkMonitor 监听 → 自动恢复消息发送（待发队列） |
| 弱网（2G/3G） | SSE 延迟增加 | 显示加载动画，不自动失败，超时 30s |

### 7.2 API 错误码处理

| 错误码 | 含义 | 客户端表现 | 处理 |
|--------|------|-----------|------|
| 400 | 参数错误 | Toast "输入内容有误" | 检查输入合法性 |
| 401 | Token 过期 | 触发自动刷新 | TokenManager 静默刷新 |
| 403 | 配额不足 | 弹窗 "今日问答次数已用完" | 引导订阅/等待次日 |
| 404 | 资源不存在 | Toast "内容不存在" | 重新加载 |
| 429 | 频率限制 | 倒计时提示 "请 N 秒后再试" | 禁用发送按钮 N 秒 |
| 500 | 服务器错误 | Toast "服务器开小差了" | 自动重试 1 次 |
| -1 | 未知错误 | Toast "出错了，请稍后重试" | 记录日志 |

### 7.3 语音异常

| 场景 | 表现 | 处理方式 |
|------|------|---------|
| 麦克风权限拒绝 | 语音按钮灰色不可用 | 弹窗引导开启权限 |
| ASR 识别失败 | 语音识别无结果 | 提示"未识别到语音，请重试" |
| ASR 超时（10s 无声音） | 自动结束录音 | 提示"未检测到语音输入" |
| TTS 引擎未安装 | TTS 按钮不可用 | 提示"请安装语音引擎" |
| 录音时来电/通知 | 录音中断 | 自动保存已录部分，显示"录音被中断" |
| 同时触发多个 TTS | 声音重叠 | 取消当前播放 → 播放最新的 |

### 7.4 多媒体异常

| 场景 | 表现 | 处理方式 |
|------|------|---------|
| 相机权限拒绝 | 拍照页面提示无权限 | 弹窗引导开启 |
| 存储权限拒绝 | 相册不可用 | 降级为仅拍照 |
| 图片过大 (>10MB) | 上传前自动压缩 | 显示"正在压缩...", 压缩至 2MB 内 |
| 不支持图片格式 | 选择时过滤 | 仅显示 JPEG/PNG/WebP |
| OCR 未检测到文字 | 无边框高亮 | 不影响拍照上传流程 |
| 相册无图片 | 缩略图显示占位图 | 提示"去拍一张吧" |

### 7.5 数据异常

| 场景 | 表现 | 处理方式 |
|------|------|---------|
| Room 数据库损坏 | 应用闪退 | 启动时检测 → 自动重建数据库 |
| 本地数据版本不一致 | 字段不匹配 | 使用 `@Database(version=...)` + Migration |
| 消息内容超长 | 截断 | UI 显示 "消息过长已截断"，保留前 2000 字 |
| SQLite 磁盘满 | 写入失败 | 提示"存储空间不足，请清理后重试" |
| 并发读写冲突 | 写入失败 | Room 事务自动重试 |

### 7.6 UI/UX 异常

| 场景 | 表现 | 处理方式 |
|------|------|---------|
| 快速点击发送（连点） | 多次发送 | 发送按钮发送后立即禁用，直到收到首个 chunk |
| 后台切回 | 流式输出状态丢失 | ViewModel 保存 state → 恢复流式输出 |
| 横竖屏旋转 | 布局重排 | Compose 自动适配，消息位置回滚到旋转前 |
| 系统字体缩放过大 | 布局错乱 | 限制最大字体倍数为 1.3x |
| 键盘弹出/收起 | 输入栏被遮挡 | `imePadding()` → 输入栏跟随键盘 |
| 超长消息（>5000 字 AI 回复） | 列表卡顿 | LazyColumn 虚拟化，消息组件懒加载 |
| 数百条消息的历史会话 | 滚动卡顿 | 分页加载，每次加载 50 条 |

二、信息的使用目的

  • 提供和维持本应用的核心功能（AI 答疑、拍照解题、语音交互、学习报告）
  • 根据您的学习行为和偏好推荐个性化学习内容
  • 分析使用数据以改进产品功能、优化用户体验
  • 回复您的咨询、处理反馈的问题
  • 检测和防范欺诈、滥用等非法活动
  • 遵守法律法规要求

我们不会将您的学习内容用于定向广告，也不会出售您的个人信息。

四、数据存储与安全

  • 传输加密：所有 API 通信使用 TLS 1.3/1.2 加密
  • 存储加密：敏感数据在服务端加密存储
  • 访问控制：仅经授权人员可访问用户数据，实施严格的审计日志
  • 数据保留：账户数据保留至注销；学习内容在账户删除后 90 天内清除
  • 本地数据：部分学习数据缓存在设备本地，可在设置中清除缓存
  • 跨境传输：服务器位于 [新加坡/美国/地区]，通过标准合同条款（SCC）保障数据传输安全

六、儿童隐私保护

本应用主要面向 K-12 学生用户。我们高度重视儿童隐私：

  • 年龄门槛：美国 COPPA（13 岁以下）、欧盟 GDPR-K（16 岁以下，各成员国可降低至 13 岁）、中国《个人信息保护法》（14 岁以下）
  • 监护人同意：未满年龄门槛的用户需在监护人同意后方可使用
  • 最小化收集：仅收集学习内容和基本资料（昵称、年级），不收集精确位置、通讯录、浏览历史
  • 无行为广告：不对儿童投放行为定向广告
  • 监护人权利：监护人可查看、删除其子女的数据，或拒绝进一步收集
  • 验证机制：可能需要监护人邮箱验证后方可激活儿童账户

如您是监护人，认为您的子女在未经您同意的情况下提供了个人信息，请立即通过隐私邮箱联系我们，我们将删除相关数据。

七、第三方分享与跨境传输

  • 不出售：我们不会向第三方出售您的个人信息
  • 无行为广告：不将数据用于跨情境行为广告
  • 服务提供商：云服务、AI 模型 API、分析服务等第三方提供商通过合同约定仅按我们的指示处理数据
  • 法律要求：如法律强制要求披露数据，在法律允许范围内将通知您

八、数据泄露通知

如果发生涉及您个人信息的數據泄露事件，我们将在发现后 72 小时内：

  1. 通知受影响用户
  2. 说明泄露的性质和范围
  3. 建议您可采取的自我保护措施
  4. 依法向相关监管机构报告
